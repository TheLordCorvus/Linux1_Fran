# Create file

Use touch to create a file

```bash

touch #file_name.file_type
```

## Create folder / directories

Use mkdir to create a folder / directory

```bash

mkdir #folder_name
```

## Remove files

Use rm to remove files

```bash

rm #file_name.file_type

```
## Move files

Use mv to move files to destination

```bash

mv #file_name.file_type  #destination directory/

```

Return file from new destination to old

```bash

cd new directory
mv file_name.file_type ..

```
